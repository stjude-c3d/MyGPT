# FAQ

## Which LLMs are supported?

We support all the LLMs available via Ollama, you can check the list of available LLMs [here](https://ollama.com/library). 

MyGPT installation instructions are using Llama3 as an example, and several LLMs are listed in the LLM tab in customization menu like following:
<img src='./images/MyGPT_LLMs_menu.png' width='800px' alt='MyGPT LLM Menu'>

Users interested in getting any other LLMs can get the model by running the following command:

```bash
ollama pull <model-name>
```
The model will be downloaded and available in the LLM tab in the customization menu.
