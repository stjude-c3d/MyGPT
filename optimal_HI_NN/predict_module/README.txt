A script to make predictions using a pre-trained Keras model (best_model.h5). It takes two numerical inputs (QRS - Question Relevancy Score and ACRS - Answer Relevancy Score with Context) and outputs a "Hallucination Index" and prediction interpretation.Requirements* Python 3.x* TensorFlow* NumPyInstall dependencies:      pip install tensorflow numpyUsageRun the script with two numerical inputs:      python predict.py <QRS> <ACRS>Example:      python predict.py 0.6 0.4Output* Hallucination Index: Predicted score.* Prediction: Either "Correct answer" or "Incorrect answer."
